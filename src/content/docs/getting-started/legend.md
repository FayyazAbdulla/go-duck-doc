The legend page is brand story, not a specification. The names in it match the stack the generator actually emits.

A Gopher (Go, concurrency) and a Duck (persistence that can change shape) agree to build a generator. **Gin** is the HTTP router. The **mark of Kratos** is the gRPC stack: Protobuf contracts on every entity. **GDL** is the language that drives all of it — one file for schema, relationships, and behavior annotations.

Those four pieces are the product:

| Story | In the generator |
|-------|------------------|
| Gopher | Go services, goroutine fan-out across silos |
| Duck | Hybrid Postgres and MongoDB |
| Gin | REST router and middleware |
| Kratos | gRPC services and auth interceptors |
| GDL | The blueprint you edit |

Continue with [GDL](/gdl/getting-started/) or the [CLI](/guides/cli/).
